Change the Prompt Color


This is a great idea, whether or not you use sudo: use ANSI escape sequences to make the prompt green for a normal user login or red for a root login.

ANSI escape sequences are non-printed text that is interpreted to change the format of some text. Their support depends on the terminal, but the color control sequences are commonly supported - see the Escape Codes page under Quick Reference on the menu for details.

The current prompt setting is the value of the PS1 environment variable, which is usually made of bash escape codes.
To see the current value, type: echo $PS1

Try a quick experiment: export PS1='\e[34m\u@\h:\e[00m\w\$ '

Using single quotes instead of double quotes when exporting your PS variables is recommended, it makes the prompt a tiny bit faster to evaluate. Leave one space at the end before the  '  to make the command line easier to read.

The PS2 environment variable is a secondary prompt, displayed when the shell waits for user input, (for example you ended a command with  \  or forgot to close your quotes). You can do the same with it, if you like.

It is important to know that all environment variables have a lifetime equal to the terminal session. In other words, when the session is closed all of the environment variables are discarded and must be redefined when a new session is started.

At login time, user environment variables are initialized from various global system files and files in the user home directory: exactly which one depends on your system, so use man bash to see the details - while you are there, look for export too. To make this easier, you can type /search term to find words in a man page.

Our system uses the global file /etc/profile when the user logs in, and a file in the user's home directory usually referred to as ~/.bashrc when we start an interactive shell that is not a login shell (a terminal in the X-windows gui, for example, or using [Ctrl] o in mc). So, if we Always want color prompts, we need to make the change in Both files, And in /etc/skel/.bashrc so every new user we create will get the proper file in their home directory.

Make it Permanent

In your root login VT, open /etc/profile in your editor.
Go down to the comment # Set a default shell prompt: - after all of the shells like ksh, zsh, ash it says 

    else
      if [ $(id -u) -ne 0 ]; then
         # non-root user
         PS1='\u@\h:\w\$ '
      else
         # root user
         PS1='\u@\h:\w\$ '
      fi
Change that part like this: 

    else
      if [ $(id -u) -ne 0 ]; then
         # non-root user
         # PS1='\u@\h:\w\$ '
         PS1='\[\033[01;32m\]\u@\h:\[\033[00m\]\w\$ '
      else
         # root user
         # PS1='\u@\h:\w\$ '
         PS1='\[\033[01;31m\]\u@\h:\[\033[00m\]\w\$ '
      fi
All done! Now make the same change to /etc/skel/.bashrc so every new user we create will get the proper file in their home directory.

Test

For your root login, type exit at the command prompt to get a new login screen. Login and start mc, then copy /etc/skel/.bashrc to /root so you will always have color prompts.

Create a new user with adduser (see the User Accounts page under Host Management on the menu for details), or if you created new users already, copy /etc/skel/.bashrc to their home directories. Open a new virtual terminal and login as this user - having a second VT means you can easily login/out to view results as a normal user and then switch over to your root shell to make any changes to the files in /etc.

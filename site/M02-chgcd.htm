Changing (virtual) CDs


Changing CDs on a running VM is quite simple:

Go to Devices at the top of the VirtualBox VM window and choose CD-DVD Devices

If there is a CD (.iso) in the drive, go back to the command line and type eject
Then go back to the VirtualBox Devices menu

Select the .iso to put in the drive, then go back to the command line and type mount /media/cdrom

That's it!

Note: The "Shared Folders" item on the VirtualBox Devices menu only works in properly configured VMs - see the Shared Folders page under Orientation on the menu for some more practical methods.

My-Tiny.Net :: Networking with Virtual Machines



mytyVM ISO (CD) Images

  1. Base.iso: the kernel and common packages. Start here. There are a few things that you need to do to finish the configuration: see mytyINSTALL.txt on the iso or Getting Started::First Things First on the menu.

  2. Config.iso: menu driven configuration
    Necessary for the lab exercises. Create a VM with the Base.iso, mount this, change the current directory to wherever you mounted this image, run ./RoleConfig and choose one role for the VM from the menu. The scripts will install the proper packages and prompt you for a reboot. There are a few things that you need to do to finish the configuration: see BaseSystem.txt on the iso for a summary or 2 through 6 on the menu for step-by-step with explanations.

    No-role Host Setup

    The Basic Configuration (No Role) option from the setup menu just does the standard cleanup and logfile setup, which is useful for many purposes. The RoleConfig script will ask you for a hostname, and configure the network to be on net-b (192.168.66/24) using the TinyNet Gateway for DHCP.

    Log in and edit /etc/HOSTNAME if you want to change that to net-a or net-c. If you want to use a static address, you also need to edit /etc/hosts. If you want to use the name of the machine, you will also need to add the name and aliases to /etc/hosts on the Gateway, so it will automatically get picked up by dnsmasq. Choose a 192.168 IP address with .56. or .66. or .76. to stay on the subnets and 2-9 or 102-109 or 250-254 to stay outside dnsmasq DHCP. Be sure to make the additions after the entries used to configure the interfaces on the Gateway.

  3. GCC.iso: C/C++ compiler and build tools.
    Not necessary for the lab exercises. Create a new VM with the Base.iso exactly as described in Getting Started::Creating VMs on the menu, except (a) give it 320mb RAM and use "Dynamically expanding storage" of 980mb in VirtualBox, and (b) in cfdisk allocate 950M to dev/sda1 and 30M to dev/sda2 (compiling is more about CPU than memory).

    Mount this iso on your VM and run install-gcc.sh to install the software and touch up the configuration. The script will insist you have 200mb free space beyond the size of the software being installed (100M).

  4. Xwin.iso: X-windows system and XFCE
    Not necessary for the lab exercises. Create a new VM with the Base.iso exactly as described in Getting Started::Creating VMs on the menu, except (a) give it 512mb RAM and use "Dynamically expanding storage" of 980mb in VirtualBox, and (b) in cfdisk allocate 950M to dev/sda1 and 30M to dev/sda2

    Mount this iso on your VM and run install-xwin.sh to install the software and touch up the configuration. The script will insist you have 200mb free space beyond the size of the software being installed: 180mb for X plus 50mb each for Wireshark and the Midori browser.

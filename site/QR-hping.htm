hping2 Quick Reference

See the man page for full details.

-V--verbose Display more information in the output
-q--quiet Display only the summary lines at start and finish
-n--numeric Numeric output (no lookup of symbolic names)
-c--count Stop after sending (and receiving) count packets
-I--interface Interface name (otherwise default routing interface)
-i--interval Wait for N seconds (uN for N microseconds)
The default is to wait one second between each packet
 --fast Alias for -i u10000 (10 packets/second)
 --faster Alias for -i u1 (1000 packets/second)
-d--data Data size (default is 0)
-E--file Filename with content to use to fill packet's data
-e--sign Content to fill first [length] bytes of data - see the man page!!
IP Packets
-a--spoof Spoof source address (replies will be sent here, so you won't see them)
 --rand-source Random source address (interesting for stress-testing firewalls)
 --rand-dest Random destination address - see the man page!!
TCP/UDP Packets
-s--baseport Base source port (default random, increased for each packet sent)
-k--keep Maintain constant source port
-p--destport Destination port (default 0)
Add + (e.g., +1024) to increase with each reply received
Add ++ (e.g., ++1024) to increase with each packet sent
TCP Packets
-M--setseq Set TCP sequence number
-F--fin Set FIN flag
-S--syn Set SYN flag
-R--rst Set RST flag
-P--push Set PUSH flag
-A--ack Set ACK flag
-U--urg Set URG flag

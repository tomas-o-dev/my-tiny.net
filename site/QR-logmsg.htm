Syslog Message Codes


The syslog daemon listens on the UNIX-domain datagram socket /dev/log to collect messages from other processes and write them to the proper log file based on the facility and priority included in the message. See the Utilities :: Netcat page on the menu for the technical details.

We can add a line to the file for messages with a given Facility and Priority with

   echo "<3>$0[$$]: --- IM IN UR BASE PLUTIN UR LAWGZ ---" | bsdnc -uU -w 1 /dev/log  

when syslog is listening on a UNIX-domain socket, or

   echo "<133>$0[$$]: --- IM IN UR BASE PLUTIN UR LAWGZ ---" | nc -u -w 1 loghost.net-r.tinynet.edu 514  

when we have a central syslog server listening on the network.

In the examples above, $0 is the name of the shell or shell script and $$ is the process id (pid) of the current shell.

The number between the angle brackets < > is the syslog Facility and Priority encoded into a single number, by first multiplying the Facility number defined in /usr/include/sys/syslog.h by 8 and then adding the number for the Priority. In the first example the Facility is KERN and the Priority is ERROR; in the second example the Facility is LOCAL0 and the Priority is NOTICE (128 + 5 = 133). RFC 5424 says leading zeros MUST NOT be used.

Here is a convenient table: just add the Priority to the Facility and you are ready to go!
